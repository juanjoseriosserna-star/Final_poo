# Final_poo
Tuve la idea de tener la clase paquetes que tenía 3 clases hijas dependiendo de el tipo de servicio que se estuviera ofreciendo, una para Estandar, para Express y para el contenido Frágil; un dato importante es que podían haber tanto guías duplicadas como guías inválidas, por lo que implementé excpeciones para estos casos y para los que decían que el peso debía estar entre ciertos datos, entre 0 y 20, por lo que también hice excepciones en caso de que fuera un número fuera de ese rango o un dato inválido. Utilicé principio solid. Utilicé un Enum de las zonas, para establecer cada zona con su respectivo precio y traté de gacer el sistema, quizás no con el resultado esperado jaja.
